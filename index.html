InfoTransfer Local text-to-speech reader for macOS

2026 · open source

Rust · GPUI · ONNX Runtime (sherpa-onnx) · Objective-C · Python · sxxrfx.github.io/infotransfer

  • Select text in any Mac app, tap one key and hear it read aloud. Built for people with dyslexia, low vision and reading fatigue; v0.1 released under Apache-2.0.
  • Speech is generated on the device by a small distilled Kokoro voice on ONNX Runtime, about 0.1 s per sentence on an M4, with no account and no network after a one-time 21 MB voice download.
  • Reads the selection through the macOS Accessibility API and speaks code, numbers and units sensibly.
  • Updates itself from GitHub Releases, checking an Ed25519 signature, SHA-256 and code-signing identity.

TLA+ Course Offline, visual course on formal specification

2026 · open source

TLA+ · HTML/JS · Python · Swift + Rust macOS app · sxxrfx.github.io/tla-plus-course

  • Follows Lamport's TLA+ video lectures, then goes beyond them into concurrency, proofs and failure-prone systems: 39 lessons, 61 problems, 206 diagrams and interactive labs in a single HTML file that works offline.
  • Problem sets model real systems: Raft-style elections, Paxos commit, write skew under snapshot isolation, leases with fencing tokens and a CRDT counter. Every spec in the course is checked with TLC.
  • A Python build lints diagrams, links and problem sets, Playwright tests cover every page, and a macOS menu-bar app serves the course locally and saves progress.

2026 · in progress, private

TypeScript · React Native · Expo

  • EPUB import, continuous reading across chapters, highlights, notes, bookmarks, search, themes and fonts, with no account; books and progress stay on the device.

EchoCatch Android notifier for new web-serial chapters

2026 · private

Kotlin · Jetpack Compose · WorkManager · Room · Jsoup

  • Checks Royal Road, Pawchive and Novel Fire in the background and posts one quiet notification per new chapter; Room deduplicates, so overlapping checks never announce an update twice.
  • Fetches over plain HTTP and falls back to a hidden WebView only to clear a Cloudflare challenge; per-site parsers are tested against saved pages.
